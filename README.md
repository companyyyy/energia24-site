# ENERGIA24

Односторінковий сайт компанії з продажу обладнання автономної енергетики **ENERGIA24**
(м. Одеса) - інвертори, акумулятори, сонячні панелі.

## Склад проєкту

| Файл | Призначення |
|---|---|
| `index.html` | Головна сторінка: hero, категорії, каталог інверторів і акумуляторів, бренди, контакти |
| `partnership.html` | Сторінка «Співпраця» з анкетою партнера |
| `style.css` | Стилі (зелений `#7CB342` / чорний / білий), адаптивна верстка, hover-ефекти |
| `script.js` | Мобільне меню, кнопки «Замовити», валідація та обробка форм |

Чистий HTML/CSS/JS без фреймворків і бекенду. Форми виводять дані в консоль браузера
та показують підтвердження користувачу.

## Запуск

Відкрити `index.html` у браузері або підняти будь-який статичний сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000
```
