# Адмінка фідів Prom.ua і сайту

- Фіди Prom (ціни, гурт, курс, наявність, клієнтські фіди): **https://energia24.com.ua/admin/**
- Редагування товарів (фото, описи, характеристики, нові товари): **https://energia24.com.ua/admin/cms/**
- Що показувати на сайті: **https://energia24.com.ua/admin/site.html** (див. «Товари на сайті» нижче)

## Фіди

| Фід | Посилання | Ціна |
|---|---|---|
| Роздріб (основний) | `https://energia24.com.ua/feed.xml` | роздрібна ціна (з фіду avtonomka або вручну) |
| Опт (клієнт PA) | `https://energia24.com.ua/pa.xml` | гуртова ціна $ × курс; товари без гуртової ціни не йдуть |
| Клієнтські фіди | `https://energia24.com.ua/feed/<назва>.xml` | правило з адмінки: роздріб або опт ± відсоток ± випадкова надбавка |

Усі фіди мають однакові товари, тексти, фото й категорії, відрізняється лише ціна
(а в опту й фідів від опту - ще й набір товарів). Посилання клієнтського фіду не змінюється,
навіть якщо змінити назву чи правило ціни.

## Ціни й наявність

- **Роздрібна ціна** для товарів з фіду avtonomka (`https://avtonomka.com.ua/feed/enerhiia24.xml`)
  оновлюється о 08:00, 13:00 і 18:00 за Києвом. Ціна, змінена в адмінці вручну (позначка «ручна»),
  діє, **поки ціна у фіді avtonomka не зміниться**; кнопка ↺ повертає ціну avtonomka. Вимкнені в
  редакторі товари не оновлюються.
- **Гуртова ціна, $** - лише вручну, до центів (`250,5`). У гривнях = ціна $ × курс (блок «Курс $ для гурту»).
  Порожньо або 0 - товар у фід опту і фіди «від опту» не йде.
- **В наявності (усі фіди)** - знята галочка = «немає в наявності» в усіх фідах (товар лишається у фідах),
  діє, поки галочку не повернуть. Стоїть - наявність як у avtonomka; товар, якого в avtonomka немає, - в наявності.
- Товар **без ціни або без фото** у фіди не йде (причину видно червоним під назвою).
- **Нові товари avtonomka** з'являються в адмінці й у фідах самі (з текстами UA/RU і фото на білому
  фоні з avtonomka); у фід опту - після того, як вписати гуртову ціну. Непотрібний - зняти галочку
  «В наявності» або вимкнути в редакторі товарів («Показувати у фідах»).
- Якщо avtonomka переносить товар на новий id з тим самим артикулом, товар автоматично переходить
  на новий id (без дубля). Якщо товар зник із avtonomka - «немає в наявності».

## Клієнтський фід

**Новий фід**: назва, основа (від роздрібу / від опту), відсоток (від −90 до +500) і/або випадкова
надбавка «від … до» в грн (цілі, можна мінусові) → **Створити**. Файл: `feed/<назва латиницею>.xml`.

| Правило | Ціна у фіді |
|---|---|
| від роздрібу, лише % | роздріб × (1 + %/100) |
| від роздрібу, % і/або надбавка | max(1, роздріб × (1 + %/100) + випадкова надбавка) |
| від опту | max(1, гурт $ × курс × (1 + %/100) + надбавка, якщо є) |

Випадкова надбавка своя для кожного товару і нова при кожному оновленні фідів. У таблиці товарів
для кожного клієнтського фіду видно розраховану ціну (для надбавки - межі «від–до»).
Змінити правило - поправити в рядку фіду і **Зберегти**. **Видалити** - посилання перестане працювати.

## Як змінити ціни

1. Відкрити https://energia24.com.ua/admin/ (вхід - токеном GitHub, див. «Перший вхід»).
2. Вписати ціну прямо в таблиці. **Enter** - до того ж поля в наступному товарі (Shift+Enter - у попередньому).
   Пробіли в числах можна («12 500»).
3. Змінені рядки підсвічуються. **Зберегти** внизу - усе одним комітом, фіди оновляться на сайті
   приблизно за 1–2 хвилини. Курс і фіди зберігаються своїми кнопками.

## Перший вхід

Потрібен акаунт GitHub з доступом на запис до репозиторію `companyyyy/energia24-site`
(власник репозиторію додає людину: Settings → Collaborators → Add people).

1. Створити токен: GitHub → Settings → Developer settings → Personal access tokens →
   **Fine-grained tokens** → Generate new token.
   - Repository access: *Only select repositories* → `companyyyy/energia24-site`.
   - Permissions → Repository permissions → **Contents: Read and write**.
   - Expiration - на свій розсуд (після закінчення терміну створити новий).
2. Відкрити https://energia24.com.ua/admin/ → вставити токен → **Увійти**.
   Для редактора товарів (`/admin/cms/`) - **Sign In with Token** і той самий токен.
   Токен зберігається лише у вашому браузері. Нікому його не пересилайте.

## Як додати товар

1. https://energia24.com.ua/admin/cms/ → **Товари → Створити**.
2. **ID товару** - наступне вільне число (найбільший ID у списку + 1).
3. Заповнити категорію, виробника, назву українською.
4. **Фото** - тільки на білому фоні (вимога Prom), бажано квадратне від 800 px.
5. **Короткий опис** - перше речення = назва товару, далі коротко основні дані.
6. **Технічні характеристики** - за бажанням, з даташиту. Російською перекладаються
   автоматично; поля «RU» заповнюйте лише для нової назви характеристики, якої
   немає в словнику (`scripts/translate_ru.py`).
7. **Ціни** - роздрібна і, за потреби, гуртова в $ (або потім на сторінці цін).
   Якщо товар є у фіді avtonomka, вкажіть «ID у фіді avtonomka» - тоді роздрібна ціна й наявність підтягуватимуться самі.
   Товари, які щойно з'явились у фіді avtonomka, створювати не треба - вони додаються самі.
8. **Save**. Через 1-2 хвилини фіди перебудуються й з'являться на сайті.

У `pa.xml` товар потрапляє, лише якщо вписано гуртову ціну.

## Як прибрати товар

Зняти галочку **Показувати у фідах** і зберегти - товар зникне з усіх фідів,
але дані лишаться. Видаляти (Delete) варто лише товари, які точно більше не потрібні.
**ID наявних товарів не змінювати** - за ним Prom.ua пов'язує товар.

## Якщо щось пішло не так

Перед оновленням фідів дані перевіряються (дублікати ID, порожні обов'язкові поля,
відсутнє фото, неправильна ціна, «dfi» у текстах, налаштування фідів тощо). При помилці фіди **не змінюються**, а в GitHub →
Actions → «Update product feed» видно, що саме не так.
Кожне збереження - окремий коміт, тому будь-яку зміну можна відкотити.

## Товари на сайті (energia24.com.ua)

**https://energia24.com.ua/admin/site.html** (або посилання «Товари на сайті →» на сторінці цін), той самий токен.

Тут вирішується, що показувати на головній сторінці сайту. Це окремо від фідів Prom:
галочка «Показувати у фідах» у редакторі товарів на сайт не впливає, і навпаки.

- **Ціни й наявність** беруться з фіду avtonomka
  (`https://avtonomka.com.ua/feed/enerhiia24.xml`) о 08:00, 13:00 і 18:00 (за Києвом) і після кожного збереження.
- **Категорії**: галочка біля категорії вмикає або вимикає всю категорію на сайті
  (разом з пунктом меню). Клік на назву показує лише товари цієї категорії.
- **Товари**: галочка «На сайті».
- **Вимкнені товари і товари вимкнених категорій з фіду не оновлюються взагалі**:
  їхні ціна й наявність лишаються такими, як були. Коли товар знову ввімкнути, ціна
  оновиться при наступній синхронізації, якщо у фіді вона встигла змінитися.
- **Ручна ціна**: вписати ціну і зберегти. Біля неї з'явиться позначка «ручна».
  Вона діє, **поки ціна цього товару у фіді не зміниться**, після чого її замінить нова ціна з фіду.
  Кнопка ↺ повертає ціну з фіду одразу. Так само працює галочка «В наявності».
- **Товар зник із фіду avtonomka**: його видаляє із сайту й з адмінки. Якщо він потім з'явиться
  знову, то додасться як новий.
- **Нові товари й категорії з фіду** додаються на сайт **одразу ввімкненими** (позначка «новий»,
  фільтр «Нові з фіду» за останні 14 днів). Картку створено з даних фіду: назва, фото, основні характеристики.
  Новий товар у вимкненій категорії (напр. «Кабельна продукція») на сайті не з'явиться, поки категорію не ввімкнути.
- Без ціни або без наявності товар показується як «Очікується» з кнопкою «Дізнатись про надходження».

Сайт оновлюється приблизно за 1–2 хвилини після збереження (GitHub Actions → «Update site catalog»).
Дані: `data/site/catalog.json`, скрипт: `scripts/site_catalog.py` (`sync`: ціни з фіду,
`build`: картки в `index.html` між маркерами `CATALOG`/`NAV`). Картки в `index.html`
вручну не редагувати, бо їх перезапише наступна збірка. Тексти карток (назва, бейдж, характеристики,
примітки) поки що міняються в `data/site/catalog.json`.

## Технічно

- Товари: `data/products/<id>.json` (`price`, `in_stock` - з avtonomka; `wholesale_usd`, `off` - з адмінки;
  `feed_price`/`feed_in_stock` - останні побачені значення avtonomka), фото: `images/products/`
  (`avt-<id avtonomka>.jpg` - завантажені з avtonomka, перевірені на білий фон: `scripts/white_bg.py`).
- Фото для опту й клієнтських фідів (якщо потрібне інше): `images/pa/<id>.jpg` - вручну.
- Клієнтські фіди й курс: `data/feeds.json`; `data/feeds_built.json` - які файли фідів побудовано
  (щоб видаляти файли прибраних фідів).
- Адмінка фідів - `admin/index.html` (комітить зміни через GitHub API).
- Редактор товарів - [Sveltia CMS](https://sveltiacms.app) у `admin/cms/`, налаштування в `admin/cms/config.yml`.
- Генерація фідів: `scripts/update_feed.py` (після кожного збереження - «Update product feed»),
  ціни й нові товари з avtonomka: `scripts/site_catalog.py sync` («Update site catalog», 3 рази на день),
  переклади: `scripts/translate_ru.py`.
