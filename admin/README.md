# Адмінка товарів для XML-фідів

- Ціни всіх товарів однією таблицею: **https://energia24.com.ua/admin/**
- Редагування товарів (фото, описи, характеристики, нові товари): **https://energia24.com.ua/admin/cms/**
  (або кнопка «Редагувати товари →» вгорі таблиці цін)

Тут редагуються товари, які йдуть у фіди Prom.ua (`feed.xml`, `pa.xml`): назва, фото,
опис, характеристики, категорія, ціни й наявність. Google-таблиці на фіди більше не впливають.

## Як змінити ціни

1. Відкрити https://energia24.com.ua/admin/ (вхід - токеном GitHub, див. «Перший вхід»).
2. Клацнути на ціну і вписати нову, прямо в таблиці. **Enter** - перейти до наступного товару (Shift+Enter - до попереднього).
   Пробіли в числах можна («12 500»).
3. Для кожного фіду окремо: **Роздріб · feed.xml** і **PA · pa.xml**.
   - «В наявності» - галочка; товар без ціни завжди йде як «немає в наявності».
   - «У фіді» (PA) - чи потрапляє товар у фід PA взагалі.
4. Змінені рядки підсвічуються. Натиснути **Зберегти** внизу - усе збережеться одним разом,
   фіди оновляться на сайті приблизно за 1–2 хвилини.

Ціни - у гривнях, рівно так, як підуть у фід.

## Перший вхід

Потрібен акаунт GitHub з доступом на запис до репозиторію `companyyyy/energia24-site`
(власник репозиторію додає людину: Settings → Collaborators → Add people).

1. Створити токен: GitHub → Settings → Developer settings → Personal access tokens →
   **Fine-grained tokens** → Generate new token.
   - Repository access: *Only select repositories* → `companyyyy/energia24-site`.
   - Permissions → Repository permissions → **Contents: Read and write**.
   - Expiration - на свій розсуд (після закінчення терміну створити новий).
2. Відкрити https://energia24.com.ua/admin/ → вставити токен → **Увійти**.
   Для редактора товарів (`/admin/cms/`) - **Sign In with Token** і той самий токен.
   Токен зберігається лише у вашому браузері. Нікому його не пересилайте.

## Як додати товар

1. https://energia24.com.ua/admin/cms/ → **Товари → Створити**.
2. **ID товару** - наступне вільне число (найбільший ID у списку + 1).
3. Заповнити категорію, виробника, назву українською.
4. **Фото** - тільки на білому фоні (вимога Prom), бажано квадратне від 800 px.
5. **Короткий опис** - перше речення = назва товару, далі коротко основні дані.
6. **Технічні характеристики** - за бажанням, з даташиту. Російською перекладаються
   автоматично; поля «RU» заповнюйте лише для нової назви характеристики, якої
   немає в словнику (`scripts/translate_ru.py`).
7. **Ціна й наявність** - для обох фідів (або потім на сторінці цін).
8. **Save**. Через 1-2 хвилини фіди перебудуються й з'являться на сайті.

У `pa.xml` товар потрапляє, лише якщо стоїть галочка «Є у фіді PA».

## Як прибрати товар

Зняти галочку **Показувати у фідах** і зберегти - товар зникне з усіх фідів,
але дані лишаться. Видаляти (Delete) варто лише товари, які точно більше не потрібні.
**ID наявних товарів не змінювати** - за ним Prom.ua пов'язує товар.

## Якщо щось пішло не так

Перед оновленням фідів дані перевіряються (дублікати ID, порожні обов'язкові поля,
відсутнє фото, неправильна ціна тощо). При помилці фіди **не змінюються**, а в GitHub →
Actions → «Update product feed» видно, що саме не так.
Кожне збереження - окремий коміт, тому будь-яку зміну можна відкотити.

## Товари на сайті (energia24.com.ua)

**https://energia24.com.ua/admin/site.html** (або посилання «Товари на сайті →» на сторінці цін), той самий токен.

Тут вирішується, що показувати на головній сторінці сайту. Це окремо від фідів Prom:
галочка «Показувати у фідах» у редакторі товарів на сайт не впливає, і навпаки.

- **Ціни й наявність** беруться з фіду avtonomka
  (`https://avtonomka.com.ua/feed/enerhiia24.xml`) щогодини і після кожного збереження.
- **Категорії**: галочка біля категорії вмикає або вимикає всю категорію на сайті
  (разом з пунктом меню). Клік на назву показує лише товари цієї категорії.
- **Товари**: галочка «На сайті».
- **Вимкнені товари і товари вимкнених категорій з фіду не оновлюються взагалі**:
  їхні ціна й наявність лишаються такими, як були. Коли товар знову ввімкнути, ціна
  оновиться при наступній синхронізації, якщо у фіді вона встигла змінитися.
- **Ручна ціна**: вписати ціну і зберегти. Біля неї з'явиться позначка «ручна».
  Вона діє, **поки ціна цього товару у фіді не зміниться**, після чого її замінить нова ціна з фіду.
  Кнопка ↺ повертає ціну з фіду одразу. Так само працює галочка «В наявності».
- **Товар зник із фіду avtonomka**: його видаляє із сайту й з адмінки. Якщо він потім з'явиться
  знову, то додасться як новий.
- **Нові товари й категорії з фіду** додаються на сайт **одразу ввімкненими** (позначка «новий»,
  фільтр «Нові з фіду» за останні 14 днів). Картку створено з даних фіду: назва, фото, основні характеристики.
  Новий товар у вимкненій категорії (напр. «Кабельна продукція») на сайті не з'явиться, поки категорію не ввімкнути.
- Без ціни або без наявності товар показується як «Очікується» з кнопкою «Дізнатись про надходження».

Сайт оновлюється приблизно за 1–2 хвилини після збереження (GitHub Actions → «Update site catalog»).
Дані: `data/site/catalog.json`, скрипт: `scripts/site_catalog.py` (`sync`: ціни з фіду,
`build`: картки в `index.html` між маркерами `CATALOG`/`NAV`). Картки в `index.html`
вручну не редагувати, бо їх перезапише наступна збірка. Тексти карток (назва, бейдж, характеристики,
примітки) поки що міняються в `data/site/catalog.json`.

## Технічно

- Товари: `data/products/<id>.json`, фото: `images/products/`.
- Фото саме для фіду PA (якщо потрібне інше): `images/pa/<id>.jpg` - поки що лише вручну.
- Таблиця цін - `admin/index.html` (комітить зміни через GitHub API).
- Редактор товарів - [Sveltia CMS](https://sveltiacms.app) у `admin/cms/`, налаштування в `admin/cms/config.yml`.
- Генерація фідів: `scripts/update_feed.py`, переклади: `scripts/translate_ru.py`.
