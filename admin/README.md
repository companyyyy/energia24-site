# Адмінка товарів для XML-фідів

- Товари: **https://energia24.com.ua/admin/**
- Ціни всіх товарів однією таблицею: **https://energia24.com.ua/admin/prices.html**

Тут редагуються товари, які йдуть у фіди Prom.ua (`feed.xml`, `pa.xml`): назва, фото,
опис, характеристики, категорія, ціни й наявність. Google-таблиці на фіди більше не впливають.

## Як змінити ціни

1. Відкрити https://energia24.com.ua/admin/prices.html (вхід - той самий, що й в адмінці).
2. Вписати нові ціни прямо в таблиці. **Enter** - перейти до наступного товару (Shift+Enter - до попереднього).
   Пробіли в числах можна («12 500»).
3. Для кожного фіду окремо: **Роздріб · feed.xml** і **PA · pa.xml**.
   - «В наявності» - галочка; товар без ціни завжди йде як «немає в наявності».
   - «У фіді» (PA) - чи потрапляє товар у фід PA взагалі.
4. Змінені рядки підсвічуються. Натиснути **Зберегти** внизу - усе збережеться одним разом,
   фіди оновляться на сайті приблизно за 1–2 хвилини.

Ціни - у гривнях, рівно так, як підуть у фід.

## Перший вхід

Потрібен акаунт GitHub з доступом на запис до репозиторію `companyyyy/energia24-site`
(власник репозиторію додає людину: Settings → Collaborators → Add people).

1. Створити токен: GitHub → Settings → Developer settings → Personal access tokens →
   **Fine-grained tokens** → Generate new token.
   - Repository access: *Only select repositories* → `companyyyy/energia24-site`.
   - Permissions → Repository permissions → **Contents: Read and write**.
   - Expiration - на свій розсуд (після закінчення терміну створити новий).
2. Відкрити https://energia24.com.ua/admin/ → **Sign In with Token** → вставити токен.
   Токен зберігається лише у вашому браузері. Нікому його не пересилайте.

## Як додати товар

1. **Товари → New Товар**.
2. **ID товару** - наступне вільне число (найбільший ID у списку + 1).
3. Заповнити категорію, виробника, назву українською.
4. **Фото** - тільки на білому фоні (вимога Prom), бажано квадратне від 800 px.
5. **Короткий опис** - перше речення = назва товару, далі коротко основні дані.
6. **Технічні характеристики** - за бажанням, з даташиту. Російською перекладаються
   автоматично; поля «RU» заповнюйте лише для нової назви характеристики, якої
   немає в словнику (`scripts/translate_ru.py`).
7. **Ціна й наявність** - для обох фідів (або потім на сторінці цін).
8. **Save**. Через 1-2 хвилини фіди перебудуються й з'являться на сайті.

У `pa.xml` товар потрапляє, лише якщо стоїть галочка «Є у фіді PA».

## Як прибрати товар

Зняти галочку **Показувати у фідах** і зберегти - товар зникне з усіх фідів,
але дані лишаться. Видаляти (Delete) варто лише товари, які точно більше не потрібні.
**ID наявних товарів не змінювати** - за ним Prom.ua пов'язує товар.

## Якщо щось пішло не так

Перед оновленням фідів дані перевіряються (дублікати ID, порожні обов'язкові поля,
відсутнє фото, неправильна ціна тощо). При помилці фіди **не змінюються**, а в GitHub →
Actions → «Update product feed» видно, що саме не так.
Кожне збереження - окремий коміт, тому будь-яку зміну можна відкотити.

## Технічно

- Товари: `data/products/<id>.json`, фото: `images/products/`.
- Фото саме для фіду PA (якщо потрібне інше): `images/pa/<id>.jpg` - поки що лише вручну.
- Адмінка - [Sveltia CMS](https://sveltiacms.app), налаштування в `admin/config.yml`.
- Сторінка цін - `admin/prices.html` (комітить зміни через GitHub API тим самим токеном).
- Генерація фідів: `scripts/update_feed.py`, переклади: `scripts/translate_ru.py`.
